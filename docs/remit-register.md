# REMIT — Discussion Register

*REMIT — Requirement, Effects & Mission Intent Tasking. The greenfield mission-planning system. (“Blockbuster” = the standalone demonstrator and idea source only, DEC-8.)*

**Purpose.** The single source of truth for the “route planning → mission planning” concept. Every idea lives here with a status and its open questions. Discussions (with Claude, the dev team, or stakeholders) end with this register updated. The eventual concept document will be distilled from **decided** entries only.

**Status key:** `raw` (captured, undiscussed) · `discussing` · `decided` · `parked` · `rejected`
**Horizon key:** `H1` near-term · `H2` mid-term · `H3` far/speculative

## A. The reframe

### A1 — Mission requirement as primary object `decided` (DEC-5/29) `H1`

**Revised per DEC-5/6.** The *mission requirement* (commitments + provenance + intent) is primary. Multiple *mission plans* respond to it; schedule and route are temporal and spatial projections of the same plan. Requirement and plan lifecycles decouple: a changed requirement re-scores existing plans rather than destroying them; the wingman monitors the chosen plan against the requirement and proposes alternative responses to the *same* requirement.

- World model placement resolved → DEC-7 (shared baseline + excursions). Data model drafted → `remit-data-model.md` v0.1 (DEC-29 representation).

### A2 — Commitment-satisfaction matrix `decided` (DEC-23) `H1`

Two-layer comparison. Objective layer: plans × commitments, verdicts (satisfied/violated/waived) + **margin bands** (robust/marginal/tight — no false decimals, NF10); appetite-independent, shareable with the command hat. Implementer layer: banded cost × robustness handful (C2). Guarded by A3 comparability (same baseline/excursion + requirement version, else warn).

### A3 — Plan assumption stamp `decided` (DEC-23) `H1`

Every plan records: appetite settings, world baseline/excursion version, requirement version. Displayed at comparison; enforces the **comparability guard** (mismatched stamps → warn). Part of the selection-rationale audit trail (NF2). Versioning granularity: per published baseline/requirement version.

### A4 — World (environment) model: facts / forecast / futures `decided` (DEC-19/20) `H2`

Per DEC-7. Three layers: **facts/observations** (one truth; plans never privately disagree), **central forecast** (agreed best estimate of evolution), **futures** (named excursions = deltas on the baseline, e.g. “storm-early”, “ford-blocked”). Plans cite the excursions they’re built/tested against. Boundary test: plans may not disagree that the storm *is* here (fact), only target different futures of it (shared, named).

- **Unifies several entries:** excursions *are* the branch points in contingency trees (C6) and the warm branches (E4); during execution an observation collapses a future into a fact (E5, C8), folding the excursion into the baseline and re-scoring all plans. Same mechanism for planning-time hedging and execution-time learning.
- **Sources (DEC-11):** synthetic and real terrain behind one interface; real = DEM + land cover rasterised to the grid, delivered as a pre-provisioned bounded AO. Synthetic ships first.
- **Structure (DEC-19):** terrain/medium (static) + pluggable risk-benefit **channels** (NF7; v1 = a small fixed set echoing Blockbuster) + time-varying **forecast**. Each channel carries value + **confidence/freshness** + its **own sampling step / predictability** (DEC-21; tide coarse/near-analytic, cloud fine + wide bands). An activity considers only its **relevant** channels (DEC-21).
- **Delta engine (DEC-19):** kernel evaluates **baseline ⊕ excursion ⊕ plan-effects-to-date**. Excursions = exogenous futures (DEC-7); activity-effects = endogenous, plan-relative, time-gated (DEC-16). Same mechanism, two sources.
- **Medium = land/sea/air (DEC-20/NF11):** channels domain-specific (slope/land-cover; bathymetry/currents/sea-state; airspace/winds/altitude); currents & winds are movement-biasing vector fields (Blockbuster cyclone precedent). Single-domain per plan in v1.
- Open: What can vary on the baseline, and how is its uncertainty modelled? (excursion-definition machinery)
- Open: v1 ships single-baseline only — confirm excursions are deferred but designed-for.

### A5 — Principles harvested from Blockbuster `raw` `H1`

Per DEC-8 the code isn’t reused, so the lessons are captured here as deliberate design tenets for the greenfield build.

- **Shared cost function (defensibility backbone):** optimiser and every view evaluate via the *same* code, so what’s shown is what was optimised. Must be a tenet, not an accident.
- **Determinism by seed:** reproducibility underpins sharing and audit.
- **Client-side / offline:** underpins shareability and the wingman (E6); don’t design in a mandatory server.
- **COA fan-out:** a reusable plan-diversity technique — lifts into the mission layer (relates to C2).

## B. Commitments — capture

### B1 — Task grammar → **Activity model** `decided` (DEC-16) `H1`

**Reframed.** A commitment generalises to an **Activity = { type, where, when/recurrence, duration, constraints, effects, outcome-model }**. The four-slot primitives are the *constraints* facet; be-at/stay-in/avoid are the simplest activity types.

- **Four-slot constraint sub-language (v1):** WHAT {be-at, stay-in(+stationary), avoid} · WHERE {waypoint | cell-predicate: land-cover, elevation, static-LOS, near(feature)} · WHEN {within-window (abs/anchored: start/midday/midnight/dawn/dusk), before/after, recurring-every(anchor)} · MODIFIERS {duration, stationary, be-at role: entry/exit/visit}. Requirement = AND of activities.
- **Richer activities exposed (driving examples):** search evasive target (coverage + detection, *probabilistic*, adversary C7); emplace barrier (*world-mutating* persistent oriented effect); loiter+monitor+unobserved (presence + info-gather + *concealment* C7, multi-day); maintenance (self-state, recurring, consumes availability C5); environmental appreciation (info-gather whose *effect is reduced forecast uncertainty* C8).
- **Three dimensions this forces into the core:** (1) **effects** — activities read *or write* the world (mutate risk, shrink uncertainty, consume self-state); kernel models effects not just costs. (2) **outcomes** beyond boolean — P(success)≥x, quantities (fits NF10). (3) **multi-scale long-horizon time** (days–weeks) → Q12 leans multi-scale; pulls C7/C8 forward as things the abstraction must *accommodate*.
- **Staging (decision pending):** adopt the Activity abstraction now; effects/outcomes pluggable (NF7). v1 types = visit, loiter/observe-lite, avoid, transit, maintain; v1 effects = self-state + simple persistent marker; v1 outcomes = boolean + duration. Deferred (H2/H3, with NF9/NF10 humility): world-mutation, probabilistic detection / evasive search, concealment, info→forecast-uncertainty, OR/at-least-N, inter-commitment sequencing, rendezvous (C9), time-varying LOS.
- Open: confirm the Activity-abstraction-now + staged-vocabulary scope (see Q16).
- Cell-predicates resolved → DEC-33 (full AND/OR/NOT grammar over pluggable atomic-predicate registry; per (cell,t), v1 atoms static).

### G6 — Worked examples: maritime tier-list & tidal-mudflat slice `raw` `H1` (feeds DEC-46)

- **Tier 1 — clean config wins (deterministic discipline + computed channels):** tide as near-analytic provider channel (DEC-21 precedent); **under-keel-clearance = bathymetry + tide(t) − draft** as a *composed* provider atom (dynamic, profile-dependent); tidal stream as the **movement vector** (`vector-field-sea`); **tidal-window transit = waiting-as-a-move (C4)** over time-varying passability — *no new discipline*; fuel/endurance as a config **cost model** (≈ f(speed-through-water³, current, sea-state)); TSS-lane / exclusion-zone region predicates; replenishment-at-sea as a state-restoring recurring effect.
- **Tier 2 — boundary (static = config, reactive = ceiling):** traffic / CPA (forecast channel ok; *reactive* traffic = multi-agent); coastal-radar concealment (as *cost* = config; as *game* = adversarial, NF1-suspending); the **provider-determinism trap is sharper at sea** — an unverifiable current field that drifts across runs silently breaks NF3/replay, so G4’s determinism test is genuinely load-bearing.
- **Tier 3 — ceiling:** SAR with **leeway drift** (drift *physics* = provider/config; allocating search effort over an evolving belief = a **stochastic discipline** — the cleanest “having the distribution vs planning against it” split); patrol **evasion** (adversarial).

The `(cell, time)` state space makes the catastrophic “stranded mid-flat” plan **infeasible for free**. **Honesty notes:** the off-map ocean is *narrative garnish* (instance-shell), not mechanism — an inland tidal ford carries identical capability while implying less than is built; tide is **forecast** (known), not **excursion** (uncertain) — a surprise surge would be the excursion (H2). Does *not* buy current-anisotropy, draft-dependent UKC, or a medium realisation — the time-varying-passability slice alone.
